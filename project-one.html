Modbus Relay Control CLI

A versatile command-line tool for managing 8-channel Modbus TCP relay boards. Designed for both automation and manual control, this Python utility offers robust features for developers and engineers working with industrial or smart building systems. Scroll down for a brief overview of the project or checkout my GitHub page for the full rundown.

Project Overview & Features

The Modbus Relay Control CLI provides a reliable and user-friendly interface for interacting with Modbus TCP relay modules. Whether you're scripting automated relay actions or performing manual tasks, this tool delivers flexibility and control with built-in logging and profile support.

🔑 Key Features

  • Dual Control Modes: Use the command-line directly or launch an interactive menu system.
  • Relay State Management:
    • Turn individual relays ON or OFF
    • Send momentary ON pulses
    • Read current relay states
    • Toggle all relays ON/OFF
  • Profile Support: Save and load named relay configurations. Profiles can be listed even without the device connected.
  • Logging: Actions are recorded to a relay_control.log file for diagnostics and auditing.
  • Auto-Reconnect: Automatically re-establishes communication if the Modbus device disconnects.

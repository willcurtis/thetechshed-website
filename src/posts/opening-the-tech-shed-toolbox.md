## More than project notes

The Tech Shed has mainly been a place to share projects, build notes and lessons learned. The new [tools section](../../tools/index.html) adds something different: practical utilities you can use directly in the browser.

The first two tools are an [IPv4 subnet calculator](../../tools/subnet-calculator/index.html) and a [Wi-Fi QR generator](../../tools/wifi-qr-generator/index.html). They are free to use, require no account and run entirely on your device.

## Starting with networking

The subnet calculator turns an IPv4 address and Classless Inter-Domain Routing (CIDR) prefix into the network range, subnet and wildcard masks, broadcast address, usable host range and address capacity. It also handles point-to-point `/31` networks and individual `/32` host routes.

The Wi-Fi QR generator creates a code that phones and tablets can scan to join a wireless network. It supports password-protected, open and hidden networks, and the finished code can be downloaded as a PNG image. Network names and passwords stay in the browser and are never uploaded.

## Just the beginning

These two utilities are the start of a broader Tech Shed toolbox. The aim is to add focused tools for networking, automation and connected technology—small enough to use immediately, but useful enough to bookmark.

Future additions will be shaped by the same approach: solve a real problem, keep the interface straightforward and explain what the tool is doing. There is plenty more on the workbench.

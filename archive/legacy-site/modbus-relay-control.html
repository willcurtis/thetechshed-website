Modbus Relay Control CLI

A command-line tool for reliable manual and automated control of eight-channel Modbus TCP relay boards.

Project overview

The tool provides a straightforward interface for industrial, home-automation and smart-building projects. It supports direct commands and an interactive menu while keeping operational details visible through logging.

Key features

  • Control individual relays, pulse outputs and read current states.
  • Switch all relays together for common operating sequences.
  • Save and load named relay profiles without requiring a live connection.
  • Record actions for diagnostics and auditing.
  • Reconnect automatically following a temporary device interruption.

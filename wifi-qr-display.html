WiFi QR Display

This started as a simple way to display a Guest WiFi login solution. Following a week of development and a number of iterations later, it has a rotating backgroud image that uses the Unsplash API to display and image and also sends a notification via telegram with the new QR and Password.

Scroll down for more details.

Details & Screenshots

This project consists of a Raspberry Pi 4 with the official 7inch touchscreen display packaged together in a case that gives it the form factor of a digital photo frame of old. Unfortunately the case was poorly designed so that the screen is actually upside down meaning some tinkering was required to rotate the screen. I opted for a touchscreen incase i wante to repurpose it afterwards but, the device now sits on a shelf in the office. The main function behind the project is that it uses the UniFi API to login to my local controller (UDM) and update the Guest WiFi password at midnight. Each time the password is changed a new QR code is generated locally for that day so that visitors can scan the QR with their phone and join the WiFi. Simple.

I couldnt stop there. It occured to me that i might need to add a device that wasn't capable of scanning a QR so I added some functionality that meant the QR and Password were sent to me each night via telegram (using their API), it also let me know how many devices were connected at the time the password was changed. I added a number of other functions as time went on including replacing the static background with one pulled from Unsplash each time the screen refreshed (once every 5 minutes as this kept me on the free-tier of their API) I was able to pass a search term to the API call so i could change the theme of the images as and when i wanted. There is also a very simple cron based function to dim and lighten the screen at certain times. The code has ben refactored a number of times to make the whole thing a little more slick.

Its not the most complex project and nor is it a professional solution but its reliable and functional. I plan to release the source once it has been built into a deployable solution. Currently it is designed to work with UniFi controllers and UniFi UDM devices but i have a version that works for Meraki and one in the pipeline for Extreme.

Hopefully I will turn the build process in to a YouTube video so look out for the link on social media.
